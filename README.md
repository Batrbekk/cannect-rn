# Vending Machine App

React Native приложение для вендингового автомата с поддержкой безналичной оплаты.

## 🚀 Особенности

- **Пейринг устройства** - подключение через 6-значный код
- **Каталог товаров** - отображение напитков в удобной сетке
- **Безналичная оплата** - только оплата банковской картой
- **Мониторинг состояния** - отслеживание остатков и статуса автомата
- **Автоматическая синхронизация** - heartbeat каждые 30 сек, состояние каждые 2 мин
- **Альбомная ориентация** - оптимизировано для планшетов Android

## 📱 Технологический стек

- **React Native** (Expo SDK 49+)
- **TypeScript** - строгая типизация
- **Zustand** - управление состоянием с персистентностью
- **React Navigation 6** - навигация между экранами
- **Axios** - HTTP клиент с автоматической аутентификацией
- **React Native Elements** - UI компоненты
- **Expo SecureStore** - безопасное хранение API ключей

## 🛠 Установка

## 🔧 Конфигурация

### API Endpoint

Обновите `BASE_URL` в файле `src/services/api.ts`:

```typescript
const BASE_URL = 'https://your-backend.com'; // Замените на ваш URL
```

### Настройка ориентации

Приложение настроено на альбомную ориентацию в `app.json`:

```json
{
  "expo": {
    "orientation": "landscape"
  }
}
```

## 📋 API Интеграция

### Эндпойнты

- `POST /api/device/pair/verify` - Пейринг устройства
- `GET /api/products` - Получение списка товаров
- `POST /api/device/{machineId}/sale` - Покупка товара
- `PUT /api/device/{deviceId}/heartbeat` - Heartbeat (каждые 30 сек)
- `GET /api/machines/{machineId}` - Состояние автомата (каждые 2 мин)

### Аутентификация

- API ключ передается в заголовке `X-API-KEY`
- Ключ сохраняется в Expo SecureStore
- Автоматический сброс при 401 ошибке

## 🔄 Жизненный цикл приложения

1. **Запуск** - проверка сохраненных данных аутентификации
2. **Пейринг** - ввод 6-значного кода для подключения
3. **Главный экран** - отображение товаров и состояния автомата
4. **Покупка** - выбор товара и оплата картой
5. **Фоновые процессы** - heartbeat и синхронизация состояния

## 🤝 Разработка

### Добавление новых экранов

1. Создайте компонент в `src/screens/`
2. Добавьте маршрут в `src/navigation/AppNavigator.tsx`
3. Обновите типы навигации при необходимости

### Добавление API методов

1. Добавьте метод в `src/services/api.ts`
2. Создайте хук в `src/services/hooks.ts`
3. Обновите типы в `src/types/index.ts`
